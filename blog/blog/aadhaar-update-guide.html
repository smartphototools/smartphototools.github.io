आधार कार्ड अपडेट कैसे करें - Complete Guide 2024

आधार कार्ड भारत का सबसे महत्वपूर्ण पहचान पत्र है। UIDAI द्वारा जारी किया जाता है। समय के साथ personal details में बदलाव आ सकते हैं - address change हो सकता है, mobile number बदल सकता है, या photo पुरानी हो गई हो।

⚡ Quick Overview

आधार में क्या-क्या update कर सकते हैं:

  • Name (नाम)
  • Date of Birth
  • Gender
  • Address (पता)
  • Mobile Number
  • Email ID
  • Photo (फोटो)
  • Biometric

आधार Update की जरूरत कब पड़ती है?

1. Address Change

  • नई जगह shift हो गए हैं
  • किसी और शहर में job के लिए गए हैं
  • Family के साथ दूसरे state में shift हुए

2. Mobile Number Update

  • पुराना number बंद हो गया
  • SIM lost हो गई
  • OTP नहीं आ रहा

3. Photo Update

  • बच्चे बड़े हो गए (10 साल से कम उम्र वालों को हर 5 साल में mandatory)
  • Appearance काफी बदल गई
  • फोटो बहुत पुरानी है

⚠️ महत्वपूर्ण

Name और Date of Birth में changes केवल valid documents के साथ ही किए जा सकते हैं।

Online Aadhaar Update - Step by Step

Requirements:

  • 12-digit Aadhaar number
  • Registered mobile number (OTP के लिए)
  • Valid email ID
  • Updated documents की scanned copy
  • Payment के लिए debit/credit card

Process:

  1. Website: myaadhaar.uidai.gov.in पर जाएं
  2. Aadhaar number enter करें
  3. OTP verify करें
  4. Update type select करें
  5. Details update करें
  6. Documents upload करें
  7. Payment करें (₹50)
  8. URN save करें

💡 OTP नहीं आ रहा?

अगर OTP नहीं आ रहा तो mobile number आधार से linked नहीं है। Aadhaar center जाना होगा।

Mobile Number Update - विस्तार से

Method 1: Online

  1. MyAadhaar portal पर login करें
  2. "Update Mobile Number" select करें
  3. नया number enter करें
  4. OTP verify करें
  5. Instant update हो जाएगा

Method 2: Offline

  1. Aadhaar center जाएं
  2. Mobile update request भरें
  3. Biometric verification होगा
  4. 24-48 hours में update

Required Documents

Address Update के लिए:

  • Passport
  • Bank Statement (3 months)
  • Ration Card
  • Voter ID
  • Driving License
  • Electricity Bill

Name Update के लिए:

  • Marriage के बाद: Marriage Certificate
  • Legal Name Change: Gazette Notification
  • Spelling Correction: Government ID

Aadhaar Update Fees

  • Mobile Number: Free
  • Email ID: Free
  • Address (First time): Free
  • Address (2nd time onwards): ₹50
  • Name/DOB/Photo: ₹50
  • Biometric (बच्चों का): Free

Common Problems और Solutions

Problem 1: OTP नहीं आ रहा

Solutions:

  • Mobile number linked check करें
  • Network issue - wait करें
  • DND deactivate करें

Problem 2: Document Reject

Solutions:

  • Document valid list में check करें
  • Expired तो नहीं
  • Clear scan upload करें

e-Aadhaar Download कैसे करें?

  1. UIDAI website पर जाएं
  2. "Download Aadhaar" select करें
  3. Aadhaar number enter करें
  4. OTP verify करें
  5. PDF download होगी
  6. Password: PIN code (capital letters)

💡 e-Aadhaar की validity

e-Aadhaar भी physical card की तरह valid है। किसी भी जगह use कर सकते हैं।

निष्कर्ष

आधार update करना अब बहुत आसान है। Online process से घर बैठे कर सकते हैं। Important यह है कि details updated रखें, specially mobile number।
