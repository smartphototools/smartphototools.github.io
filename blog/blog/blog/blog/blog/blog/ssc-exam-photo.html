SSC परीक्षा के लिए Photo और Signature कैसे बनाएं

Staff Selection Commission (SSC) हर साल CGL, CHSL, MTS, CPO, GD जैसी कई परीक्षाएं conduct करता है। इन सभी exams के online application में photo और signature upload करनी पड़ती है। गलत size या format की वजह से हजारों applications reject हो जाती हैं।

⚡ SSC Photo Quick Requirements

  • Photo Size: 20 KB - 50 KB
  • Signature Size: 10 KB - 20 KB
  • Format: JPEG/JPG only
  • Dimensions: 3.5×4.5 cm (photo), 140×60 pixels (signature)
  • Background: सफेद या हल्का रंग

SSC Exams की Photo Requirements

Photo की विस्तृत Specifications

Photo Requirements:

  • Dimensions: 3.5 cm × 4.5 cm (passport size)
  • File Size: 20 KB से 50 KB के बीच (strict requirement)
  • File Format: केवल JPEG/JPG (PNG नहीं चलेगा)
  • Background: सफेद या बहुत हल्का रंग
  • Face Coverage: चेहरा 70-80% फोटो में होना चाहिए
  • Recent Photo: 3 महीने से ज्यादा पुरानी नहीं
  • Color: Color photograph (B&W नहीं)

Photo में क्या होना चाहिए:

  • सीधे camera की ओर देखना
  • Neutral expression (हल्की मुस्कान OK है)
  • दोनों आँखें खुली और clearly visible
  • औपचारिक कपड़े (formal attire)
  • साफ-सुथरा background
  • चेहरे पर कोई shadow नहीं

⚠️ Photo में क्या नहीं होना चाहिए

  • Sunglasses या tinted glasses
  • Cap, hat या head gear (धार्मिक कारण को छोड़कर)
  • Background में कोई और व्यक्ति या object
  • Filters या heavy editing
  • Tilted head या side pose

Signature की Requirements

Signature Specifications:

  • Dimensions: 140×60 pixels या 3.5×1.5 cm
  • File Size: 10 KB से 20 KB के बीच
  • Format: JPEG/JPG only
  • Background: सफेद
  • Ink Color: काली या नीली (recommended: काली)
  • Clear: साफ और readable

Perfect Signature कैसे बनाएं:

  1. सफेद कागज पर काली pen से signature करें
  2. अच्छी रोशनी में photo लें (shadow न हो)
  3. Smart Photo Tools पर upload करें
  4. Automatic background remove होगा
  5. Exact size में download करें

SSC Application में Upload कैसे करें?

Step-by-Step Process:

  1. SSC की official website पर जाएं
  2. अपना application form भरना शुरू करें
  3. Personal details भरने के बाद photo/signature upload section आएगा
  4. "Browse" button click करके photo select करें
  5. Upload होने के बाद preview देखें
  6. फिर signature upload करें
  7. दोनों properly display हो रहे हैं check करें
  8. Save और proceed करें

💡 Upload करने से पहले

  • File size जरूर check करें (properties में देखें)
  • File name simple रखें (कोई special characters नहीं)
  • Backup copy रखें
  • अलग-अलग browsers में try करें अगर error आए

Common Mistakes और Solutions

Mistake 1: File Size बहुत बड़ी

समस्या: Photo 50 KB से ज्यादा है।

समाधान:

  • Smart Photo Tools के compressor use करें
  • Exact 40-45 KB में compress करें
  • Quality 80-85% रखें

Mistake 2: Wrong Format

समस्या: PNG या अन्य format में है।

समाधान:

  • JPEG में convert करें
  • Paint या online converter use करें
  • Extension .jpg या .jpeg होना चाहिए

Mistake 3: Background Dark है

समस्या: Colored या dark background।

समाधान:

  • सफेद दीवार के सामने नई photo लें
  • Background editing tools avoid करें
  • Natural white background prefer करें

Mistake 4: Signature Blurry है

समस्या: Signature साफ नहीं दिख रहा।

समाधान:

  • Better lighting में photo लें
  • Camera को steady रखें
  • Black pen use करें (thick stroke)

Mobile से Photo कैसे लें?

Setup:

  • सफेद दीवार या सफेद चादर background के लिए
  • Window के पास खड़े हों (natural light)
  • दीवार से 1-2 feet दूर खड़े हों

Photo लेते समय:

  • Rear camera use करें (selfie नहीं)
  • किसी से photo खिंचवाएं
  • Camera को eye level पर रखें
  • Multiple photos लें, best select करें

SSC Admit Card पर Photo कैसी दिखेगी?

Admit card download करने के बाद:

  • Photo और signature दोनों print होंगे
  • Black & white print में भी clear दिखना चाहिए
  • Exam center पर verification के लिए use होगी
  • अगर match नहीं करती तो problem हो सकती है

⚠️ महत्वपूर्ण

जो photo application में upload की है, वैसी ही photo admit card पर print होगी। Exam के दिन भी same appearance maintain करें (haircut, facial hair, etc.)।

Different SSC Exams की विशेष Requirements

SSC CGL (Combined Graduate Level):

  • Standard requirements same हैं
  • Tier-1 admit card पर photo print होगी
  • Document verification में original photo चाहिए होगी

SSC CHSL (Combined Higher Secondary Level):

  • Photo requirements CGL जैसी ही
  • Typing test के time भी verification होता है

SSC GD (General Duty):

  • Physical fitness test भी होता है
  • Photo में clear face दिखना जरूरी
  • Medical examination में भी photo verify होती है

FAQs

Q: क्या चश्मा पहनकर photo ले सकते हैं?

A: हाँ, regular prescription glasses OK हैं। Sunglasses नहीं। Reflection नहीं होनी चाहिए।

Q: Signature English में होना चाहिए या Hindi में?

A: कोई भी language/script acceptable है। जो normally use करते हैं वही बनाएं।

Q: अगर photo upload में error आ रहा है?

A: File size और format check करें। Browser cache clear करें। Different browser try करें।

Q: क्या application submit के बाद photo change कर सकते हैं?

A: नहीं। Submit के बाद changes नहीं हो सकते। Correction window में भी photo change allowed नहीं होता usually।

निष्कर्ष

SSC exam के लिए photo और signature upload करना simple है अगर सही specifications follow करें। Key points:

  • File size strictly 20-50 KB (photo), 10-20 KB (signature)
  • केवल JPEG format
  • सफेद background
  • Recent photo (3 months)
  • Clear और readable signature

Smart Photo Tools use करके आप perfect size और format में photos बना सकते हैं। Upload से पहले preview जरूर देखें।
