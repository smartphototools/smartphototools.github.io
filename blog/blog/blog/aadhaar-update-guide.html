आधार कार्ड अपडेट कैसे करें - Complete Guide 2024

आधार कार्ड (Aadhaar Card) भारत का सबसे महत्वपूर्ण पहचान पत्र है। UIDAI द्वारा जारी किया जाता है। समय के साथ आपकी personal details में बदलाव आ सकते हैं - address change हो सकता है, mobile number बदल सकता है, या photo बहुत पुरानी हो गई हो।

⚡ Quick Overview

आधार में क्या-क्या update कर सकते हैं:

  • Name (नाम)
  • Date of Birth
  • Gender
  • Address (पता)
  • Mobile Number
  • Email ID
  • Photo (फोटो)
  • Biometric

आधार Update की जरूरत कब पड़ती है?

1. Address Change

  • नई जगह shift हो गए हैं
  • किसी और शहर में job के लिए गए हैं
  • Family के साथ दूसरे state में shift हुए

2. Mobile Number Update

  • पुराना number बंद हो गया
  • SIM lost हो गई
  • OTP आधार पर registered number पर नहीं आ रहा

3. Photo Update

  • बच्चे बड़े हो गए (10 साल से कम उम्र वालों को हर 5 साल में update करना mandatory है)
  • Appearance काफी बदल गई
  • फोटो बहुत पुरानी है

⚠️ महत्वपूर्ण

Name और Date of Birth में changes केवल valid documents के साथ ही किए जा सकते हैं। Address, mobile number और photo update आसान हैं।

Online Aadhaar Update - Step by Step

Requirements:

  • 12-digit Aadhaar number
  • Registered mobile number (OTP के लिए)
  • Valid email ID
  • Updated documents की scanned copy
  • Payment के लिए debit/credit card

Step 1: UIDAI Website पर जाएं

  • Browser में myaadhaar.uidai.gov.in open करें
  • "Update Your Aadhaar" option select करें

Step 2: Login करें

  • 12-digit Aadhaar number enter करें
  • Captcha code भरें
  • "Send OTP" click करें
  • OTP enter करके verify करें

💡 OTP नहीं आ रहा?

अगर OTP नहीं आ रहा तो mobile number आधार से linked नहीं है। Aadhaar center जाना होगा।

Step 3: Update Type Select करें

Options:

  • Demographic Update: Name, DOB, Address, Mobile, Email
  • Document Update: नए documents upload
  • Biometric Update: Online नहीं हो सकता

Step 4: Details Update करें

Address Update:

  • नया address सही-सही भरें
  • Proof of Address document upload करें

Mobile/Email Update:

  • नया number/email enter करें
  • कोई document नहीं चाहिए

Step 5: Documents Upload करें

  • Clear photo या scan upload करें
  • File size 2 MB से कम
  • Format: JPEG, PDF, PNG

Step 6: Payment करें

  • ₹50 fee (address/demo update के लिए)
  • Debit card, Credit card, UPI से pay करें
  • URN (Update Request Number) मिलेगा
  • इस URN को save करें

ℹ️ Free Updates

कुछ updates free हैं:

  • Mobile number और email - Free
  • First time address update - Free
  • बच्चों का biometric (5, 10, 15 साल में) - Free

Update Status कैसे Check करें?

  1. UIDAI website पर जाएं
  2. "Check Aadhaar Update Status" select करें
  3. URN enter करें
  4. Status दिखेगा: Pending, Under Process, Approved, या Rejected

💡 Processing Time

Normal processing time 7-10 working days है। Approved होने के बाद updated e-Aadhaar download कर सकते हैं।

Offline Aadhaar Update - Center में जाकर

Nearest Center कैसे ढूंढें?

  1. UIDAI website पर जाएं
  2. "Locate an Enrolment Centre" select करें
  3. State, District select करें या PIN code enter करें
  4. Nearest centers की list मिलेगी

Center जाने से पहले तैयारी:

  • Original Aadhaar Card साथ लें
  • Original Documents (जो update करना है उसके लिए)
  • Photo (अगर photo update करनी है)
  • Cash/UPI (₹50 fees के लिए)

Center में Process:

  1. Token लें
  2. Update request form भरें
  3. Documents submit करें
  4. Biometric scan होगा
  5. Photo ली जाएगी (अगर update कर रहे हैं)
  6. Acknowledgement slip मिलेगी URN के साथ
  7. Fee payment करें

⚠️ Center जाते समय ध्यान दें

  • सुबह जल्दी जाएं - कम भीड़
  • Original documents ज़रूर लें
  • Operator को carefully देखें कि सही details enter कर रहा है
  • Receipt संभालकर रखें

Required Documents

Address Update के लिए Proof of Address:

  • Passport
  • Bank Statement (3 महीने से कम पुरानी)
  • Ration Card
  • Voter ID Card
  • Driving License
  • Electricity Bill
  • Water Bill
  • Property Tax Receipt

Name Update के लिए:

  • Marriage के बाद: Marriage Certificate
  • Legal Name Change: Gazette Notification
  • Spelling Correction: Government ID जिसमें सही spelling हो

Mobile Number Update - विस्तार से

Method 1: Online (अगर OTP आ रहा है)

  1. MyAadhaar portal पर login करें
  2. "Update Mobile Number" select करें
  3. नया number enter करें
  4. नए number पर OTP verify करें
  5. Instant update हो जाएगा

Method 2: Offline (अगर OTP नहीं आ रहा)

  1. Aadhaar center जाएं
  2. Mobile update request भरें
  3. Biometric verification होगा
  4. 24-48 hours में update

Photo Update - कब और कैसे

Photo Update कब जरूरी है?

  • बच्चों के लिए Mandatory: 5, 10, 15 साल में (free)
  • Adults: Optional लेकिन recommended अगर appearance बहुत बदल गई
  • Photo बहुत पुरानी हो: 10+ साल

Aadhaar Photo Specifications:

  • Size: 3.5 cm × 4.5 cm
  • Background: सफेद या हल्का
  • Face coverage: 70-80%
  • Recent: 6 महीने से कम पुरानी
  • File format: JPEG
  • File size: 10-50 KB

Common Problems और Solutions

Problem 1: OTP नहीं आ रहा

Solutions:

  • Check करें mobile number linked है या नहीं
  • Network issue - थोड़ा wait करें
  • DND deactivate करें
  • Aadhaar center जाएं

Problem 2: Document Reject हो गया

Solutions:

  • Document valid list में check करें
  • Expired तो नहीं है
  • Clear scan/photo upload करें
  • Alternate document try करें

e-Aadhaar Download कैसे करें?

  1. UIDAI website: uidai.gov.in पर जाएं
  2. "Download Aadhaar" select करें
  3. Aadhaar number enter करें
  4. OTP verify करें
  5. PDF download होगी
  6. Password: PIN code (capital letters में)

💡 e-Aadhaar की validity

e-Aadhaar भी physical card की तरह valid है। किसी भी जगह use कर सकते हैं। Color print करें।
