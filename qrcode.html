2. रूप-रंग

रंगों में अंतर कम है, इसलिए QR स्कैन होने में दिक्कत आ सकती है। गहरा रंग और हल्की Background चुनें।

आपका QR Code

PNG आम इस्तेमाल के लिए है। SVG प्रिंट के लिए, क्योंकि बड़ा करने पर भी साफ़ रहता है।

QR Code के उपयोग

  • Link: अपनी वेबसाइट, Google Form या Portfolio का Link।
  • WhatsApp: दुकान या सेवा पर सीधे चैट शुरू करवाने के लिए।
  • Wi-Fi: मेहमानों को पासवर्ड बताए बिना जोड़ने के लिए।
सुझाव: Print करने से पहले अपने फोन के कैमरे से एक बार स्कैन करके ज़रूर जाँच लें। Wi-Fi QR में पासवर्ड होता है, इसलिए उसे सोच-समझकर साझा करें।

अक्सर पूछे जाने वाले सवाल

क्या QR Code बनाने के लिए Login या पैसे लगते हैं?

नहीं। QR Code मुफ्त बनता है और Login की ज़रूरत नहीं है।

क्या मेरा Text या Link आपके Server पर जाता है?

नहीं। QR Code आपके Browser में ही बनता है। आपका Link, Text या Wi-Fi पासवर्ड हमारे Server पर नहीं भेजा जाता।

QR Code स्कैन नहीं हो रहा, क्या करें?

रंगों में अंतर (Contrast) साफ़ रखें, यानी गहरा रंग हल्की Background पर। बहुत छोटा Size या बहुत लंबा Text भी परेशानी करता है। Error correction बढ़ाकर देखें।

QR Code कितने समय तक चलेगा?

इस Tool से बना QR Code सीधे आपका Text या Link रखता है, इसलिए यह हमेशा चलेगा। बस Link वाली साइट चालू रहनी चाहिए।
